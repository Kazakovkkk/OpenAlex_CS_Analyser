# Анализ формирующихся научных направлений в сфере информационных технологий на основе данных OpenAlex

Курсовой проект по дисциплине «Наука о данных и аналитика больших объемов информации».

## О проекте

Система предназначена для сбора, хранения и анализа научных публикайи в сфере информационных технологий (Computer Science) на основе данных **OpenAlex** с целью выявления зарождающихся научных направлений.

## Задачи анализа

1. Выявление некорректных и ошибочных записей в собранном наборе данных о научных публикациях.
2. Определение динамики научных тем по годам.
3. Определение периодов взрывного роста интереса к научным темам.
4. Выявление зарождающихся научных тем на основе совокупности признаков.
5. Проверка точности выявления зарождающихся тем по статистике последующих лет.
6. Определение стран и научных организаций, в которых зарождаются новые направления, и скорости их распространения в другие страны.

## Технологический стек

* **Сбор и нормализация данных:** Go
* **Хранилище данных (DW):** ClickHouse
* **Аналитика и визуализация:** Python
* **Инфраструктура и дистрибутив:** Docker / Docker Compose
